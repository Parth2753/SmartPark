 # Task-99 SmartPark
SmartPark is a cutting-edge, single-page web application for efficient parking management. Developed entirely with HTML, CSS, and JavaScript, it delivers an interactive parking lot visualization with real-time spot availability tracking. Users can easily select and reserve spots through an intuitive interface that works flawlessly across desktops, tablets, and mobile devices. No server or backend setup required—everything runs smoothly in the browser.
​

---
# Features
1) Interactive Parking Grid: Visual representation of parking spots with color-coded status (green for available, red for occupied).
<br>
2) Real-Time Updates: Instant feedback on spot selection with smooth animations and hover effects.
<br>
3) Responsive Design: Fully adaptive layout using CSS Flexbox and Grid for optimal viewing on any screen size.
<br>
4) User-Friendly Controls: Simple clik-to-reserve functionality, with options to reset or customize lot configurations
<br>
5) Accessibility Ready: Semantic HTML, keyboard navigation, and screen reader compatibility.
<br>
6) Performance Optimized: Lightweight code with no external dependencies for fast loading times.
<br>
7) Customizable: Easily modify spot counts, layouts, or add features via JavaScript variables.
